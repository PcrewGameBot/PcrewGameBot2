PCREW GAME BOT - COUPLE COURT (LDR ONLY)
========================================

FEATURES
- Telegram Mini App invitation link: Create Couple Invite, copy/share the link, partner opens and accepts.
- Invite token is single-use; a Telegram user can belong to one couple at a time.
- No owner permission grant is required.
- Owner panel remains for listing couples and removing/restoring access.
- Relationship mode: LDR available; In-Person and Both are Coming Soon. Both partners must choose LDR.
- User-written case title and free-form complaint; partner submits a free-form response.
- Random 50/50 GUILTY / NOT GUILTY after response. Guilty gets a backend-selected LDR punishment.
- 400 LDR punishments; no repeat per couple until the pool is exhausted, then reset.
- Case history and Telegram notifications.

RAILWAY VARIABLES
Keep existing variables. Add/confirm:
BOT_USERNAME = your bot username without @ (required for invite links)
OWNER_ID = your numeric Telegram user ID (required for Owner Panel)

OWNER COMMANDS
/id
/couples
/remove CPxxxxxx
/restore CPxxxxxx

DEPLOY
1. Extract this ZIP and upload all project files to the existing GitHub repository root.
2. Keep existing Railway database volume/data. Do not delete scores.db or the mounted /data volume.
3. Set BOT_USERNAME and OWNER_ID in Railway Variables.
4. Commit and allow Railway to deploy. Test invite links with a second Telegram account.

This update does not add Love Court, Funny Court, XP, Levels, Frame Shop, or XP sales.
Python syntax and bundled punishment count are checked locally; live Railway deployment has not been performed.
